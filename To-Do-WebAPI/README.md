# To-Do Web API 🚀

A high-performance, production-ready backend system built with C#, the .NET ecosystem, and PostgreSQL.

---

## 🛠️ Project Roadmap & Versions

### 🔹 Version 2.0 (Latest Milestone)
* **Advanced Query Engine:** Implemented server-side pagination (`.Skip()` and `.Take()`), multi-field text search across titles and descriptions, and boolean status filtering.
* **Architecture Upgrade:** Migrated the codebase to the **Repository Pattern** to completely decouple database logic from API endpoints.
* **Data Integrity:** Added robust model validations and data annotations to secure input fields.

### 🔹 Version 1.0 (Core CRUD)
* Basic relational database registration using Entity Framework Core.
* Traditional Create, Read, Update, and Delete endpoints connected to PostgreSQL.
